# Настройка корпоративного режима (SQL Server)

## Требования
- SQL Server Express (бесплатно) или SQL Server любой редакции
- Сеть между компьютерами сотрудников

## Шаг 1 — Установка SQL Server Express
Скачай с официального сайта Microsoft:
https://www.microsoft.com/ru-ru/sql-server/sql-server-downloads
→ выбери "Express" → установи

## Шаг 2 — Создай базу данных
Открой SQL Server Management Studio (SSMS) или выполни в cmd:
```sql
CREATE DATABASE ClientAccountDb;
```

## Шаг 3 — Настрой доступ
В SSMS → безопасность → добавь пользователя Windows или SQL-логин.
Пример строки подключения:
```
Server=ИМЯ_СЕРВЕРА\SQLEXPRESS;Database=ClientAccountDb;Integrated Security=true;TrustServerCertificate=true;
```

## Шаг 4 — В приложении
1. Параметры → Корпоративная база данных → Открыть настройки подключения
2. Введи строку подключения
3. Нажми "Проверить подключение" — убедись что работает
4. Нажми "Сохранить серверный режим"
5. Нажми "Перенести SQLite → SQL Server" чтобы скопировать данные
6. Перезапусти приложение

## Шаг 5 — Установка на других компьютерах
На каждом компьютере сотрудника:
1. Установи приложение (распакуй ZIP)
2. Параметры → Корпоративная база → введи ту же строку подключения
3. Сохрани → перезапусти

Теперь все работают с одной базой!
